# Midas Core — JPMorgan Chase Transaction System

A financial transaction processing microservice built as part of the 
JPMorgan Chase Software Engineering Virtual Experience on Forage.

## Tech Stack
- Java 17
- Spring Boot 3.2.5
- Apache Kafka
- Spring Data JPA
- H2 Database
- REST API

## Features
- Kafka listener for real-time transaction processing
- Transaction validation (sender/recipient/balance checks)
- Database persistence using JPA
- External Incentive API integration
- REST endpoint for querying user balances
